# Modelo por planos - original de Kaoru Studio

El modelo implementado en:
legacy/3d-lighting/js/asaroHead.js

es una geometria original creada para este proyecto.

No contiene ni descarga un archivo OBJ, GLB, GLTF u otro modelo Asaro
de terceros.

Objetivo:
crear una cabeza de estudio artistico con superficies suficientemente
diferenciadas para observar cambios claros de valor producidos por la luz.

La estructura facial se divide en 52 superficies planas y utiliza una
geometria facetada adicional para craneo y cuello.

El nombre "Asaro / Planos" describe el tipo de ejercicio artistico de
cabeza por planos. La geometria concreta de este proyecto es propia.
