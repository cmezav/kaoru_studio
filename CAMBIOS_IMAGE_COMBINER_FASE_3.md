# Image Combiner Studio - Fase 3 de 6

## Crop no destructivo por imagen
- Crop X.
- Crop Y.
- Ancho visible.
- Alto visible.
- Preset original.
- Preset 1:1.
- Preset 4:5.
- Preset 5:4.
- Preset 16:9.
- Preset 9:16.
- Ajustar marco al aspecto real del recorte.
- Restablecer crop.
- La fuente original nunca se destruye.

## Bordes múltiples
- Hasta 6 bordes por imagen.
- Cada borde tiene:
  color libre,
  HEX,
  grosor,
  opacidad.
- Los bordes se apilan desde el interior hacia afuera.
- Se exportan en PNG.

## Sombra
- Activar / desactivar.
- Color libre + HEX.
- Dirección de -180 a 180.
- Distancia de 0 a 200.
- Desenfoque de 0 a 120.
- Opacidad de 0 a 100.

## Resplandor
- Activar / desactivar.
- Color libre + HEX.
- Desenfoque de 0 a 120.
- Opacidad de 0 a 100.

## Ajustes visuales por capa
- Brillo.
- Contraste.
- Saturación.
- Blur.
- Escala de grises.
- Reset rápido.

## Exportación
- El PNG usa el mismo crop, filtros, sombra, glow y bordes que el preview.
- Las imágenes ocultas no se exportan.
- Fondo transparente continúa funcionando.
- Prefijo CMB-.

## Compatibilidad
- Conserva selección múltiple.
- Conserva panel de capas.
- Conserva alineación y distribución.
- Conserva Ctrl+D, Ctrl+A, Ctrl+Z, Ctrl+Shift+Z.
- Conserva drag & drop y Ctrl+V.
