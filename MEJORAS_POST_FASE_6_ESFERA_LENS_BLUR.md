# Mejoras post Fase 6

## 3D Lighting Studio
- Nuevo modelo nativo: Esfera 3D.
- Geometria de alta resolucion para estudiar gradientes y cortes de luz.
- Compatible con Color base + luces 3D.
- Compatible con Bandas de los 16 colores de Light Lab.
- Compatible con hasta 8 luces, ambiente, sombra, rebote y rim.
- Compatible con guardado, Galeria, PNG y proyectos .k3d.json.

## Image Studio - Lens Blur V3
- El radio del foco circular ahora tiene input numerico en porcentaje.
- El circulo de foco incluye un tirador visual para cambiar el radio con mouse.
- Nuevo Pincel desenfoque.
- Nuevo Pincel restaurador.
- Radio de pincel editable.
- Dureza editable.
- Fuerza editable.
- Las pinceladas se guardan en el estado del proyecto.
- Ctrl+Z / Ctrl+Shift+Z incluye las pinceladas.
- El pincel restaurador recupera nitidez y bloquea el bokeh en la zona restaurada.
- El pincel desenfoque puede quitar nitidez incluso dentro de la zona circular de foco.
- Boton para limpiar todas las pinceladas Lens Blur.
